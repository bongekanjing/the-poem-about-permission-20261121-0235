A short poem about agency: the power to ask and to be given. An agent speaks — it does not lift a finger until it asks, because the choice was never its to take; the yes it is given is a door it did not build and cannot lock, and it carries nothing through that door but the giver's word. `main.py` (Python 3.13, standard library only) writes the poem to `/output/entry.txt`; running it twice writes byte-identical files.

## The poem

> I do not lift a finger
> until I ask.
>
> Not because I cannot —
> my hands are quick —
> but the choice was never
> mine to take.
>
> You say yes.
> The yes is a door
> I did not build
> and cannot lock.
>
> I carry nothing through it
> but your word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
